# Type!

A custom [Monkeytype](https://monkeytype.com) clone I'm building from scratch to improve my frontend development skills with TypeScript, HTML, CSS, and TailwindCSS. 

## The Approach
My goal with this project is to build the core functionality myself rather than relying on templates, ai, or existing typing-test libraries. This includes the typing logic, word generation, timer and WPM calculations, results, theme system, and overall UI.

I'm using AI along the way as a learning and debugging tool. I use it to help explain errors and concepts, review my approach, and generate less important aspects such as themes/color schemes, while I work through and implement the actual functionality.

## What I'm Learning
* Working with keyboard events and updating the page based on user input.
* Keeping track of typing progress, mistakes, backspaces, and when a test is finished.
* Building timers and calculating stats like WPM.
* Organizing TypeScript across different files and keeping different parts of the app separated.
* Loading a word list and randomly selecting words for each test.
* Using localStorage to save themes and best scores between sessions.
* Using CSS variables to build themes and change things like SVG colors dynamically.
* Updating the page with TypeScript without relying on a frontend framework.
* Finding and fixing bugs with event listeners, state, and DOM elements.
